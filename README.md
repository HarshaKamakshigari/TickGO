# ✅ TickGo

A simple and fast Todo CLI app written in Go — track your tasks right from your terminal!

---

## 🚀 Features
- Add new tasks
- List all tasks
- Mark tasks as completed
- Delete tasks
- Persistent local storage (JSON or DB)
- User-friendly CLI using [Cobra](https://github.com/spf13/cobra)

---

## 📦 Installation

```bash
git clone https://github.com/HarshaKamakshigari/TickGO.git
cd TickGO
go build -o tickgo
./tickgo
